# KMPメモ帳 ブランチ運用

このリポジトリは、KMP講座で使いやすいように「作業用ブランチ」と「答えブランチ」を分けています。

## 受講者が最初に使うブランチ

```bash
git switch handson/start
```

`handson/start` は、ハンズオン開始用のブランチです。最小限の画面だけが入っていて、講座中に Step 1-1 から順番に実装していきます。

## 完成版を見るブランチ

```bash
git switch answer/final
```

`answer/final` は、KMPメモ帳の完成版です。講師のデモ、答え合わせ、復旧用に使います。

## Stepごとの答えブランチ

各 Step の完了状態を確認したいときは、次のブランチに切り替えます。

```text
answer/step-1-1-memo
answer/step-1-2-add-memo
answer/step-1-3-list-delete
answer/step-1-4-search
answer/step-1-5-favorite-sort
answer/step-2-1-expect
answer/step-2-2-time-actual
answer/step-2-3-storage-common
answer/step-2-4-storage-actual
answer/step-2-5-autosave
answer/final
```

たとえば Step 1-4 の答えを見たい場合は、次のようにします。

```bash
git switch answer/step-1-4-search
```

## 作業中の変更がある場合

作業途中で答えブランチへ移動しようとすると、Git に止められることがあります。その場合は、いったん変更を退避します。

```bash
git stash -u
git switch answer/step-1-4-search
```

自分の作業に戻る場合は、`handson/start` または自分で作った作業ブランチに戻ってから、退避した変更を戻します。

```bash
git switch handson/start
git stash pop
```

## 講師向けメモ

講座中は、基本的に受講者へ `handson/start` から始めてもらいます。

詰まった人には、該当 Step の `answer/...` ブランチを見てもらうと復旧しやすくなります。全員で答え合わせをするときは、講師側だけが `answer/final` や各 Step ブランチを使う運用にすると、受講者の作業ツリーが散らかりにくいです。
